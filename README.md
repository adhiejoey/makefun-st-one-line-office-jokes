One single-line office joke that turns on a painfully real detail — the
out-of-office reply — and lands its laugh in the last few words: the only
document the company ever produced that tells the truth, because it admits
the sender is gone and nobody can reach them.

## How it works

`main.ts` (Node 22, standard library only, no network) writes the joke to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), checking first that it
stays inside the 1–199 character gate.
